Install / 安装

  1. Download the signed DMG from the GitHub Release.
  2. Move Monster Expedition.app to /Applications.
  3. Add the GitHub Marketplace in Codex, install the plugin, then start a new task.
  4. Ask Codex to open Monster Expedition. Codex Link is optional.

若 Gatekeeper 拦截安装，请验证 Release 已签名并公证；不要绕过未签名构建。
