# Uninstall

1. In Monster Expedition settings, disconnect Codex Link. This removes only the marked Monster Expedition OTel block from `~/.codex/config.toml`.
2. Quit the Pet from its contextual menu.
3. Delete `/Applications/Monster Expedition.app`.
4. Optional: delete `~/Library/Application Support/Monster Expedition/` to remove the local save, Pet bridge, socket, and diagnostic data.
5. Remove the plugin from Codex and remove its Marketplace if no longer needed.

No account or cloud data exists to delete.
